## 使用例

オン・オフの切り替えと2つの選択肢の切り替えのどちらにも、Ark UIの`Switch.Root`と各slotを組み合わせます。2つの選択肢を切り替える場合は`variant="mode"`を指定します。

Slot Recipeのvariant軸は`variant`で、値は`onOff`または`mode`です。既定値は`onOff`です。
