## Breaking Change

Ark UIの`Drawer`コンポーネント追加に伴い、v0.4.0以降では、`placement`属性を廃止し、`swipeDirection`属性に変更。

```tsx
<Drawer.Root
  placement="right"  // [!code --]
  swipeDirection="end"  // [!code ++]
>
```

| placement | swipeDirection |
|-----------|----------------|
| `left`  | `start`      |
| `right` | `end`        |
| `top`   | `up`         |
| `bottom` | `down`      |
