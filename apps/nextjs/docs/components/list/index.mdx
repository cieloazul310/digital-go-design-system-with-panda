## MDXの順序付きリスト

`OrderedList`は、項番を各`List`の子要素として明示するコンポーネントです。Markdownの`1.`形式を使う場合は、MDXの`ol`マッピングで項番をテキストの`<span>`として挿入してください。この変換はMDX環境に依存するため、共通コンポーネントのsnippetには含めず、利用するアプリの`mdx-components.tsx`に実装します。

```tsx
import {
  isValidElement,
  type ComponentProps,
} from "react";
import type { MDXComponents } from "mdx/types";
import { List, OrderedList } from "@/components/ui/list";

type MarkdownOrderedListProps = ComponentProps<typeof OrderedList> & {
  start?: number;
};

type MarkdownListItemProps = ComponentProps<typeof List> & {
  value?: number;
};

function MarkdownOrderedList({
  children,
  start = 1,
  ...props
}: MarkdownOrderedListProps) {
  const items = Array.isArray(children) ? children : [children];
  const numberedItems = items.map((child, index) => {
    if (!isValidElement<MarkdownListItemProps>(child)) return child;

    const { children: itemChildren, value, ...itemProps } = child.props;
    const number = value ?? start + index;
    const ListItem = child.type;

    return (
      <ListItem key={child.key ?? `ordered-list-item-${number}`} {...itemProps}>
        <span>{number}.</span>
        {itemChildren}
      </ListItem>
    );
  });

  return <OrderedList {...props}>{numberedItems}</OrderedList>;
}

export function useMDXComponents(components: MDXComponents): MDXComponents {
  return {
    ol: MarkdownOrderedList,
    ...components,
  };
}
```

この例は通常の10進数の項番を対象としています。独自の項番表記や厳密な番号付けが必要な場合は、Markdownの自動採番に任せず、`OrderedList`内の`List`に項番をテキストで明記してください。
